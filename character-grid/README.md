# 作业 3：字符田字格（教材 P196 5.1）

运行：`python tianzige.py 4`（参数 = 每边格子数，默认 2；纯标准库）。代码只有一个文件，约 25 行。

## 思路

整张图其实只有两种行，用字符串乘法一次生成：

```python
border = ("+" + "-" * 10) * n + "+"    # 边框行
body   = ("|" + " " * 10) * n + "|"    # 格身行
```

每个小格 = 1 条边框行 + 4 条格身行，最后再补一条底边，所以总共 `5n+1` 行、每行 `11n+1` 个字符。

题目要求的「**函数方式 + 宽度参数**」就是 `tian(n)`：把尺寸提成参数，函数返回整张图的字符串，换 n 就换大小，`n=2` 是 11 行、`n=4` 是 21 行。

> 输出要用等宽字体看；中文全角符号或比例字体会让格线错位。
