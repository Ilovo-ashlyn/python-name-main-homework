## 一、题目要求

教材第 5 章程序练习题 5.1：**用字符方式打印输出一个"更大的田字格"**，

> 编写程序，用字符方式打印输出一个简单的田字格，输出效果如图 5.12 / 5.16 所示。要求采用**函数方式**，以**田字格宽度为参数**，能够根据参数绘制**任意大小**的田字格。

教材样例的规格（也是课后参考答案 `tian(n)` 采用的口径）：每边 `n` 个小格，每格 10 个短横、4 行格身。

| 项目 | 公式 | n=4 时 |
| --- | --- | --- |
| 总行数 | `n × (1+4) + 1 = 5n+1` | 21 行 |
| 每行字符数 | `n × (1+10) + 1 = 11n+1` | 45 字符 |
| 边框行位置 | 行号 `0, 5, 10, …`（每 5 行一条） | 第 0/5/10/15/20 行 |

> 关于「宽度」的两种理解：课后答案把 `n` 当作**每边格子数**；也有同学把它理解成**每格横线数**。本项目两种都支持——`tian(n)` 按教材答案口径，`build_grid(cell_width=…)` 控制每格字符宽，`cols/rows` 控制格子数量，怎么要求都能覆盖。

## 二、把图形拆成两种行

看起来是复杂网格，其实整张图只有**两种行**在交替：

```python
border = ("+" + "-" * 10) * n + "+"   # 边框行：交点 + 10 短横，重复 n 次，补末尾交点
body   = ("|" + " " * 10) * n + "|"   # 格身行：竖线 + 10 空格，重复 n 次，补末尾竖线
```

每个小格 = 1 条边框行 + 4 条格身行，最后再补 1 条底边：

```
总行数 = n × (1 + cell_height) + 1
每行宽 = n × (1 + cell_width)  + 1
```

这里全部用**字符串乘法和拼接**一次生成整行，不需要两层循环逐字符拼，也不需要 `end=""` 拼半行——这正是这一章想练的「把重复工作交给表达式」。

## 三、为什么必须用函数

如果不封装，画 4 格就得抄 21 行 `print`，换一个尺寸全部重写。把尺寸提成一个参数之后：

```python
def tian(n: int) -> str:
    return build_grid(cols=n)
```

- **一个参数控制任意大小**：`tian(2)`、`tian(4)`、`tian(8)` 都是同一段代码；
- **便于复用**：`build_grid()` 返回字符串，既能 `print`，也能写文件、做单元测试、嵌进博客；
- **规格可先算后验**：`grid_spec()` 先给出应有行列数，写完代码有数可对。

这就是第 5 章「函数与代码复用」的重点：不是把 `print` 搬进函数里，而是把**变化的部分抽象成参数**。

## 八、容易踩的坑

- **必须用等宽字体**：`+`、`-`、`|`、空格在等宽字体里都占 1 格，格线才齐；用比例字体或中文全角字符（`＋`、`—`、`｜`）会歪。
- **别写成中文破折号**：有些博客答案用 `"— "`（全角长横 + 空格），宽度是 ASCII 的 3 倍，输出会错位。
- **别漏最后一条底边**：循环里每个小格只画上边框，结束必须再补一条，否则少 1 行。
- **字符串乘法要带括号**：`("+" + "-"*10) * n + "+"`，写成 `"+" + "-"*10 * n + "+"` 优先级就错了。
- **参数要校验**：`0`、负数、小数、字符串、`True` 都应明确报错，而不是画出莫名其妙的图形或死循环。
- **`print` 还是 `return`**：教材答案直接 `print`；本项目让 `build_grid()` 返回字符串，`draw_grid()` 负责打印，方便测试和复用。
- **终端行宽**：`n=8` 时每行 89 字符，终端太窄会折行，看起来像画错了，其实只是显示问题。

## 九、还能怎么扩展

- 行列不等：`build_grid(cols=3, rows=2)` 画 2 行 3 列的矩形网格；
- 换风格：`Style(cross="*", horizontal="=", vertical=":", fill=".")`；
- 格内标记：把 `fill` 换成坐标字符，或在 `body` 中插入行列号，就能做坐标版田字格；
- 写入文件：`Path("grid.txt").write_text(build_grid(4))`，交作业直接贴文本。

## 十、结论

这道题的核心不是「会画格子」，而是**把重复结构抽象成两种行、把尺寸抽象成参数、用函数把两者包起来**。一旦拆清楚，任意大小、任意字符、任意行列都是同一段代码；再用 `grid_spec()` 先把规格算出来，写完就有客观标准可以核对——这也是这份作业附带自检脚本的原因。
