# 作业 6：孤独的古诗词（教材 P205 实例 6A）

运行：`python lonely_poem.py`（PyCharm 里点 ▶ 也行）→ 控制台直接打印结果。
纯标准库，不用装任何包；代码只有一个 `.py`，38 行。

## 题目与思路

- **实例 6A**：一首诗若每个汉字均不同，称为「孤独的古诗词」。去掉标点后比较 `len(s)` 和 `len(set(s))`，相等就说明没有重复字。《独坐敬亭山》20 个字全不同 → `True`。
- **练习 6.3**：换成《静夜思》，「明、月、头」重复 → `False`，程序还会把重复的字列出来。想试别的诗，改 `main()` 里的诗句字符串即可。
- **练习 6.1**：列表**有序、元素可重复、按下标访问**；集合**无序、元素唯一、能做交并差**。`set(a)` 把列表转集合（自动去重），`list(b)` 转回列表（顺序不固定，可写 `sorted(b)` 排好）。
- **练习 6.2**：`S1={1,3,5,6}`、`S2={2,5,6}`，四个运算结果见下方实测输出。

## 实测输出

```text
《独坐敬亭山》孤独吗？ True
《静夜思》孤独吗？ False，重复的字：头、明、月
列表 [3, 1, 2, 3, 2] -> 集合 {1, 2, 3} -> 列表 [1, 2, 3]
S1 | S2 = {1, 2, 3, 5, 6}    S1 & S2 = {5, 6}
S1 ^ S2 = {1, 2, 3}    S1 - S2 = {1, 3}
```
