# 需求澄清清单（交付物 1 · 初稿，请本人修改）

> 说明：本清单应在把任务交给 AI **之前**书面写清。以下是根据实验文档整理的事实框架，
> 标注 `[待补充]` 的地方请填入你自己的判断后再提交。

## 1. 目标

在 60 分钟内完成两道 Python 实操题，产出可一键运行、可验证、异常不崩溃的工程，
并保留 AI 协作过程记录。评分看「结果 + 过程 + 验证 + 风险 + 复盘」五维。

- 考题一（必做，40 分）：`sales_raw.xlsx` → 清洗统计 → `report.xlsx`（四个 sheet）
- 考题二（做核心）：FastAPI 记账接口，`POST /records` / `GET /records` / `GET /summary`

## 2. 输入输出

| 项 | 考题一 | 考题二 |
|---|---|---|
| 输入 | `sales_raw.xlsx`，6 字段：日期、销售员、产品、数量、单价、地区；含空值、重复行、负数量 | JSON 流水：金额、类型、分类、日期；查询参数：类型、分类、日期区间、分页 |
| 输出 | `report.xlsx` 四表：明细清洗后 / 按销售员 / 按地区 / 总览 | `201` 记录、`{total,page,page_size,items}`、`{income,expense,balance}` |
| 副作用 | **不得修改原始文件** | 内存存储，不落盘 |

## 3. 边界与约束

- 清洗顺序：删关键字段缺失 → 剔数量≤0 → 全字段去重；销售额 = 数量 × 单价
- 异常输入必须有**可读**报错：文件不存在、0 字节、只有表头、缺列、清洗后无有效数据
- 校验：金额 > 0；类型只能是「收入/支出」；日期 `YYYY-MM-DD`；非法参数 4xx + 结构化错误
- 分页：`page ≥ 1`、`1 ≤ page_size ≤ 100`；日期区间不能倒置
- 环境 Python ≥ 3.10；允许库：pandas、openpyxl、fastapi、uvicorn、pytest、httpx（httpx 供 TestClient）
- 并发写入不产生数据错误（能说明保证方式即可）

## 4. 验收标准

1. `python excel_report.py` 一键生成正确报表，三张汇总表之和与人工核对一致
2. 异常输入不崩溃、有中文可读提示；`sales_raw.xlsx` 哈希前后不变
3. 接口可启动并可调用；校验用例返回预期状态码
4. `pytest` 覆盖核心用例，正常用例 + 至少 2 个边界/异常用例
5. 附运行结果截图、AI 协作记录、文字复盘
