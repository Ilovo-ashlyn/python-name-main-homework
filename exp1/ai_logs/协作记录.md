## 我拍板的几个决定

- **先澄清再动手**：第一轮只允许读文档，不写代码；计划我确认了才开始。
- **拆小步、每步立刻验**：8 批推进，写完一小块就实跑，出问题当场改。
- **限制改动范围**：前面 6 份作业、exp2、exp3 的代码一行没动。
- **限制依赖**：只新装 openpyxl / fastapi / pytest / httpx 这 4 个。Starlette 提示 `httpx` 以后要被 `httpx2` 取代，我没让装，只在 README 里记了一句。
- 一开始就定死的两条口径：报错要能直接看懂，别甩英文 Traceback；三张汇总表都得跟手算的 270 对上。
- 我亲自接管的：跑脚本核 270、全量 `pytest`、真实起 `uvicorn` 打 HTTP 请求、看 `run_output.png` 截图、比对原始文件哈希。

## 中间改过的地方

1. `tests/test_excel_report.py` 第一版「缺列」那个用例的表头拼错了，会先撞上「没有数据行」，测不到「缺少必需字段」。改成 `header / data / keyword` 三参数化，8 个用例才全过。
2. `ledger_api.py` 第一版写了个没用上的 `RecordOut`，直接删掉了，不留冗余。
3. 总览那行是「合计」不是一笔销售，核对时别把它再累加一遍，不然会看成 540。
4. 用 urllib 验证中文查询参数时，直接拼 URL 会报 `UnicodeEncodeError`，加 `urllib.parse.quote` 才通。
5. `pytest` 会生成 `.pytest_cache/`，加进 `.gitignore` 了，没混进提交。
