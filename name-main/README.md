# 作业 1：`if __name__ == '__main__':` 的含义与 why

运行：`python name_main.py`（纯标准库，不用装包）。代码只有一个文件，20 行。

## 一句话

`__name__` 是解释器自动给每个模块加的变量：**直接运行**的文件叫 `__main__`，**被 import** 的文件叫自己的模块名。所以这行 `if` 就是「我是入口吗？」的开关。

## 怎么看出区别

```python
print("顶层", __name__)          # 不管怎么加载，都会执行

if __name__ == "__main__":
    main()                      # 只有直接运行时才执行
```

1. 运行 `python name_main.py` → 打印顶层 + main 两段，`__name__ = __main__`。
2. 在同目录新建 `a.py`，只写一行 `import name_main`，运行 `python a.py` → 只打印顶层那段，`__name__ = name_main`。

## 为什么要写

`import` 会把被导入文件的**顶层代码从头执行一遍**。把演示、测试、启动代码放进保护块，别人只想用你的函数时，就不会被迫打印一堆东西或触发别的动作。约定写法是：先定义 → 再判断 → 最后调用 `main()`。
