# 作业 5：统计「十五五」规划报告热词频率

运行：`python wordfreq.py`（PyCharm 里点 ▶ 也行）→ 控制台直接打印热词榜。
依赖：`pip install jieba`（本机 PyCharm 的 venv 已装好，jieba 0.42.1）。

## 思路

1. `report.txt` 是《中华人民共和国国民经济和社会发展第十五个五年（2026－2030 年）规划纲要》全文（新华社受权播发，中国人大网，约 5.8 万字）。**换语料只要替换这个 txt**，代码一行都不用改。
2. `jieba.posseg` 分词并带词性；用 `jieba.add_word()` 把「新质生产力」等报告专有名词加进词典，避免被切碎。
3. 只保留 **2 字以上的中文名词 / 动名词**，并跳过 `STOP` 里的虚词。这样「推进、加强、完善」这类公文动词不会霸榜，留下来的才是主题热词。
4. `collections.Counter` 统计频次，`most_common(20)` 输出榜单。

代码只有一个 `.py`，43 行，纯文本输出，不需要图形界面。
