# 中文分词笔记

中文不像英文有空格，做文本分析之前要先分词。jieba 是常用的中文分词库，精确模式能把句子切得比较准，适合词频统计和关键词提取。

## 精确模式和自定义词典

精确模式用 lcut 直接返回词语列表。遇到专业术语时，默认词表可能把一个词拆开，这时候要加载自定义词典，把「词云」「停用词」「关键词提取」这类词加进去，分词结果才对。

## 停用词表

停用词表是每行一个词的纯文本文件，保存成 UTF-8。读取之后转成集合，分词时逐个判断，过滤掉没有信息量的词。停用词表可以按领域自己补充，比如分析技术文档时把「介绍」「说明」也加进去。

## 关键词和词云

统计词频之后取前五十个高频词，用词云展示最直观。词云的尺寸、背景色、最多词数都可以调，中文字体路径一定要写对。关键词报告则按文档分别列出核心词，比只看一张图更方便核对。
